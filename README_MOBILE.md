# SQL学习游戏 - 移动版本

## 项目介绍

这是SQL学习游戏的移动版本，支持在Android和iOS设备上运行。本项目基于Web技术开发，使用HTML5、CSS3和JavaScript，通过WebView技术在移动设备上运行。

## 技术栈

- **前端**：HTML5, CSS3, JavaScript
- **SQL引擎**：SQL.js (WebAssembly版本)
- **移动平台**：通过WebView技术支持Android和iOS
- **响应式设计**：适配不同屏幕尺寸

## 功能特性

### 核心功能
- ✅ 真实SQL引擎执行
- ✅ 关卡式学习模式
- ✅ 语法学习和提示
- ✅ 表结构查看
- ✅ 答案验证
- ✅ 标签标记功能

### 移动端专属优化
- ✅ 响应式布局（支持手机、平板）
- ✅ 触摸事件支持
- ✅ 长按操作（替代右键）
- ✅ 移动端友好的UI设计
- ✅ 触摸反馈动画

## 如何在移动设备上运行

### 方法1：直接通过浏览器访问

1. 将项目部署到Web服务器
2. 在移动设备的浏览器中访问项目URL
3. 建议添加到主屏幕以获得类似原生应用的体验

### 方法2：使用WebView封装（原生应用）

#### Android
1. 使用Android Studio创建一个新的WebView应用
2. 将项目文件复制到`assets`目录
3. 配置WebView加载本地HTML文件

#### iOS
1. 使用Xcode创建一个新的WebView应用
2. 将项目文件添加到项目中
3. 配置WKWebView加载本地HTML文件

## 移动端适配说明

### 屏幕尺寸适配
- **手机**：单列布局，关卡列表显示在顶部
- **平板**：双列布局，与桌面端一致
- **小屏幕**：优化字体大小和间距

### 触摸交互
- **点击**：选择关卡、执行SQL、查看提示
- **长按**：标记/取消标记关卡、查看语法提示
- **触摸反馈**：按钮点击时有缩放动画

### 性能优化
- **WebAssembly**：SQL.js使用WebAssembly提高执行性能
- **响应式设计**：根据设备性能自动调整布局
- **资源加载**：优化资源加载顺序，提升启动速度

## 开发指南

### 本地开发
1. 克隆项目：`git clone https://github.com/wenbo030509/SqlGame.git`
2. 切换到移动分支：`git checkout feature/mobile-app`
3. 启动本地服务器：`python3 -m http.server 8000`
4. 在浏览器中访问：`http://localhost:8000`

### 测试
- 使用Chrome DevTools的设备模拟功能测试不同设备
- 在真实移动设备上测试触摸交互
- 测试不同网络环境下的性能

## 已知问题

- 在某些旧设备上可能存在WebAssembly兼容性问题
- 首次加载时可能需要较长时间（WebAssembly文件较大）
- 移动设备上的SQL执行性能可能不如桌面端
